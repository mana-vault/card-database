# 設計:mana-vault card-database

## ねらい

このデータベースのねらいは、カードを、データセットとして正しく定義することです。

そのために、まず二つのことが必要です。

1. カードに名前を付け、安定して識別できるようにすること。
2. カードには、ルールが定める部品だけを持たせ、商品や言語の情報はカードの外に置くこと。

## カード

Magic のルールは、カードがどのようなものかを定めています。カードは、カード名とマナ・コスト、色、タイプ行、ルール・テキストから成るゲームのオブジェクトです。タイプ行は、特殊タイプとカード・タイプ、サブタイプから成ります。カード・タイプによっては、パワーとタフネス、忠誠度、守備値が加わります。ルールはまた、両面カード、分割カード、出来事カード、バトルのように、一枚のカードが複数の面を持つことを認めています。

このデータベースでは、この部品の集まりを`カード`と呼びます。`カード`の値は英語です。ゲームは Wizards of the Coast が作っており、英語が基準になるためです。部品の名前は、公式ルールの言葉に従います。商品や言語の情報は、`カード`に入りません。

`カード`には種類があります。通常のほか、変身する両面カードやモードを持つ両面カード、分割カード、出来事カード、バトルのように、複数の面を持つ種類があります。値の持ち方は、種類ごとに決まります。通常の`カード`は、部品の値を直に持ちます。複数の面を持つ種類では、面の名前の項目で面ごとの値を持ちます。持ち方を、種類の間で一つの形に共通化することはしません。それぞれの種類に、その持ち方のスキーマがあります。

`カード`は、一度登録したら同一性が変わらないものとして登録します。値が間違っていれば、見つかったときに直します。

## プリント

商品の中では、同じカードがいつも同じ形で並ぶとは限りません。セットはカードを再録します。言語ごとに、紙面のカード名やテキストは異なります。コラボ商品は、カードを別名で載せます。`カード`が一つの商品の中に現れるものを、`プリント`と呼びます。

`プリント`は、`カード`とは別のデータとして持ちます。セットとコレクター番号、言語、レアリティ、アーティスト、画像 URL に加え、その紙面に印刷された値を持ちます。値が英語と同じところは、書かれません。`プリント`は、自分の属する`カード`を名前で指します。
