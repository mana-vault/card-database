# mana-vault card-database

Magic: The Gathering のカードデータを、JSON ファイルで公開するデータベースです。

データは三種類に分かれます。

- `カード`は、ゲームのルールで定められたオブジェクトです。カード名、マナ・コスト、タイプ行、ルール・テキストなどを英語で記録します。両面カードなどは、各面の情報を分けて記録します。
- `翻訳`には、ある言語のカードに印刷される値のうち、英語と異なるものだけを記録します。
- `プリント`は、カードが商品に収録されたときの情報です。セット、コレクター番号、言語、レアリティ、イラストレーターを記録します。

各`プリント`は、元となる`カード`を参照します。カードに印刷される値は、`カード`のデータにその言語の`翻訳`を反映して組み立てます。データ形式については、[設計文書](design.md)をご覧ください。

カードデータの追加や修正については[貢献するには](contributing.md)、利用条件については [LICENSE](../../LICENSE) をご覧ください。
