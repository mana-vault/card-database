# mana-vault card-database

Magic: The Gathering のカードの情報を、構造化した JSON ファイルとして公開するデータベースです。

データは二つの側でできています。1つは`カード`で、Magic のルールが定めるオブジェクトとしての情報です。カード名やマナ・コスト、タイプ行など、ルールで定まる部品の値が、英語だけで並びます。もう1つは`プリント`で、その`カード`が商品に載ったときの1枚ぶんの情報です。セットとコレクター番号、言語、レアリティ、イラストに加え、その言語の紙面に印刷された名前やテキストも持ちます。

`プリント`は必ず、自分が属する`カード`を参照します。商品や言語の情報が`カード`の側に入ることはありません。データの形式のくわしい説明は、[`design.md`](design.md) をご覧ください。

`カード`のデータを追加・修正したい方は [contributing.md](contributing.md) を、利用の範囲は [LICENSE](../../LICENSE) をご覧ください。
