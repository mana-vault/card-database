# mana-vault card-database

Magic: The Gathering のカードデータを、JSON ファイルで公開するデータベースです。

データは二つの層に分かれます。

- `data/oracle/` は、`カード`をゲームのルールで定められたオブジェクトとして構造化して収録します。マナ・コスト、色、タイプ行、ルール・テキスト、両面カードの各面などです。セットもここに収録します。言葉は一切含みません。
- `data/print/` は紙そのものを、言語ごとのフォルダで収録します。`プリント`は、カードが商品に収録されたときの情報で、セット、コレクター番号、言語、媒体、レアリティ、イラストレーター、その印刷のフレイバー・テキストを収録します。プリントの隣には、その言語の紙面が示す言葉も置きます。プリントごとのカード名・タイプ行・ルール・テキストと、コンポーネントやセットの名称です。

各`プリント`は、元となる`カード`を参照し、同じ見え方の言葉のファイルと対になります。フレイバー・テキストだけは`プリント`のものです。データ形式については、[設計文書](design.md)をご覧ください。

カードデータの追加や修正については[貢献するには](contributing.md)、利用条件については [LICENSE](../../LICENSE) をご覧ください。
