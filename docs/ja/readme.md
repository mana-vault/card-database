# mana-vault card-database

Magic: The Gathering のカードデータを、JSON ファイルで公開するデータベースです。

データは三種類に分かれます。

- `カード`は、ゲームのルールで定められたオブジェクトを、印刷されたものではなく、ルールにしたがって構造化して収録します。マナ・コスト、色、タイプ行、ルール・テキスト、両面カードの各面などです。
- 言語ファイルには、ある言語の紙面に刷られる言葉を収録します。カード名、タイプ行、ルール・テキスト、フレイバー・テキストです。
- `プリント`は、カードが商品に収録されたときの情報です。セット、コレクター番号、言語、媒体、レアリティ、イラストレーターを収録します。

各`プリント`は、元となる`カード`を参照します。紙面の言葉は言語ファイルのものです。データ形式については、[設計文書](design.md)をご覧ください。

カードデータの追加や修正については[貢献するには](contributing.md)、利用条件については [LICENSE](../../LICENSE) をご覧ください。
