# 貢献するには

カードデータベースの改善にご協力いただき、ありがとうございます。

## 貢献の種類

カードデータは `data/` に、JSON Schema は `schema/` に、設計文書は `docs/` にあります。貢献では、これらのいずれかを追加または変更します。

| 貢献 | 内容 |
| --- | --- |
| `カード` | `data/card/normal/li/lightning-bolt.json` のようなカードファイルを追加します。カードが参照する部品の値は、`data/card/component/` の一覧から id で指定します。 |
| `プリント` | `data/print/ja/sta/105.json` のように、プリントごとにファイルを一つ作ります。セットのデータは先に登録しておきます。 |
| 公式の訂正 | Wizards of the Coast が訂正を発表したら、該当する値を修正し、カードまたは翻訳の `history` に記録を追加します。記録の形式はスキーマで定めています。 |
| スキーマと文書 | `schema/` または `docs/` を変更します。設計が決まっていない場合は、先に Issue で相談してください。 |

## 手順

1. 編集する`カード`、セット、`翻訳`のデータを確認します。
2. ファイルの形式と置き場所は [design.md](design.md) に従います。編集したファイルが対応するスキーマに合っていることも確認してください。
3. プルリクエストを作成し、説明に `card_id` または `set_code` を記載します。スキーマや文書を変更する場合は、設計を決めた Issue へのリンクも記載してください。

## レビューで確認すること

- 変更した値が、対象カードに実際に印刷されている内容と一致していること。セット、カード名、マナ・コスト、レアリティも確認します。
- 文字列がカードの印刷どおりであること。空白や改行も一致させます。
- 変更に含まれるすべてのファイルが、対応するスキーマに適合していること。
- 新しい `card_id` が [design.md](design.md) の規則に従い、既存の id と重複していないこと。
- 公式訂正の記録が `history` に追加され、過去の記録が書き換えられていないこと。
