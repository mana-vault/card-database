# 貢献するには

カードデータベースをよくするご協力、ありがとうございます。

| 貢献 | 内容 |
| --- | --- |
| 新しい`カード`を加える | `カードのファイル`を書きます。データの形式と置き場所は [design.md](design.md) をご覧ください |
| 既存の`カード`のデータを直す | 誤字、まちがった値、足りない`プリント`の情報の修正 |
| 問題を Issue で報告する | `カード`の内容やデータの形式で気になった点 |

## 手順

1. その`カード`がすでに `data/cards/` の中にないか確かめます。
2. [design.md](design.md) のファイル形式と名前の付け方に従います。`カードのファイル`は `data/cards/<初出のセット>/<card_id>.json` の場所に置きます。`初出のセット`とは、その`カード`が最初に載った商品です。
3. プルリクエストを出します。説明文には `card_id` か `set_code` を書いてください。

## レビューで見る点

- 各値が、参照している`カード`の実物に載っている内容と合っていること。`セット`、名前、コスト、レアリティも含めます。
- 文字列が`カード`の実物に載っているとおりであること。空白や改行も変えません。
- `card_id` が [design.md](design.md) のルールに従っていて、すでにあるものと重複しないこと。
