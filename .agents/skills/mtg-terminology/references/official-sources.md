# Official Magic sources

- [English Comprehensive Rules](https://magic.wizards.com/en/rules) is the full rules reference.
- [Japanese rules page](https://magic.wizards.com/ja/rules) provides basic rules only. It does not
  currently publish a Japanese Comprehensive Rules document.
- [Japanese keyword glossary](https://magic.wizards.com/ja/keyword-glossary) gives official
  Japanese wording for common Magic terms.
- [English keyword glossary](https://magic.wizards.com/en/keyword-glossary) gives official English
  wording for common Magic terms.
- [Wizards card database](https://gatherer.wizards.com/Pages/Default.aspx) lets you check the text of
  a specific printing and language.
